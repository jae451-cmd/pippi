CASE 1Percutaneous Pedicle Screw Fixation

MIS 경피적 척추경 나사 고정술

L2–L5 골절에 작은 절개로 screw 8개를 박는 수술이에요. 옆으로 넘기면서 순서대로 보면 됩니다.

레벨
L2–L5
Screw / Cage
8 개 / 3 개
Rod

Bovie

메모
  • L1 Fx여도 안정성 위해 하나만 박는 게 아니라 4개 박음 — 45 · 45 · 50 · 45 (변동 가능), rod 110
  • Lateral 상태에서 screw 박음 (어느 정도 박으면 guide wire 제거)
  • inj burr L1~3 (메모 그대로)
준비체위드레이핑TrocarWire·DBM·ScrewRodCap·Final봉합
STEP 1수술 전 준비

Screw 색부터 외우기

5.5 초록 6.5 파랑 7.5 보라
  • 발판 2개 — surgeon용 + 업체용
  • Suction tube는 고무 막가위로 자름
  • Rod holder로 rod 길이 재고 중간 marking
  • Inner 빼는 sliding hammer(원통) 준비
잊지 말기수술 시작하면 타이머 켜기
STEP 2체위 · Prone

엎드린 자세로, 배는 띄워서

  1. Foley 삽입
  2. 머리·다리 방향 바꿔 bed 거꾸로
  3. 팔판에 베개 → 다리 안 처지게
  4. 가슴·골반 반시트, prone bar에 베개 넣어 lordosis 더 주기
  5. ST 방수포 → C-arm 원통 위로, 살짝 tilting
  6. Bovie·suction은 다리 쪽, allis 2개로 고정 (bovie·suction tube)
  7. Bovie·suction은 kelly 2개로 고정 — lateral포 때문에 kelly 하나 더
STEP 3드레이핑 · lapa drape

순서대로 덮기

  1. Marking → C-arm 베타딘
  2. Utility 사각드랩
  3. 다리쪽 중포 1 · 머리쪽 중포 1
  4. ST 닫고 아이오반 전체 붙이기
  5. 대공포 텐팅, 사각 모서리 쪼아 붙이기
  6. Bovie · suction · C-arm 정리
STEP 4척추경 진입

Trocar를 mallet으로

  1. Freer marker → mess 15 incision
  2. Bovie·손가락 박리 → 검정 핸들 trocar 물려서 전달
  3. Pedicle 위치 잡으면 mallet으로 진입
  4. 검정 handle 분리 → trocar 더 때려 넣기
  5. 같은 레벨 옆에도 하나 더
Trocar베벨형(경사면)이 기본. 안 들어가면 원뿔형
꽉 낄 때U자 hammer · 손으로 빼기 · sheath는 plier로
C-armLateral마다 새 중포. AP 땐 kelly 풀고 중포 떨어뜨리기
STEP 5가장 바쁜 구간

Wire → DBM → Screw

  1. 머리쪽 trocar부터 inner 받고 guide wire 전달 → sheath out
  2. VP needle(RAPO)을 wire 따라 넣고 wire 잠깐 빼기
  3. DBM 1cc 중 0.5cc → inner silver로 밀기 → wire 다시
  4. 4레벨 중 3레벨만 DBM (총 3개)
  5. 6.5×50 driver + 동그란 sleeve, thread 일자로 → ① sleeve 내리고 ② 스프링 내려 고정
  6. Wire 따라 screw → 들어가면 wire out → 반복
  7. Lateral로 깊이 check, 반대쪽 Rt도 동일
주의Screw 건넬 때 handle 위로 — sleeve 빠짐 방지
보조Screw 들어갈 땐 freer로 피부 잡아주기
STEP 6Rod 삽입

머리 → 다리, 손잡이는 surgeon 쪽

  1. T silver handle + rod handle(100)로 대보기 → 길이·bending 결정
  2. Rod + marking pen + 자 → 숫자 적힌 안쪽 C자에 marking
  3. 필요하면 bender로 lordosis 맞춰 bending (등 부분은 튀어나오고 허리 부분은 움푹 들어감)
  4. Handle에 rod 고정 → driver로 위에서 아래로
  5. Freer로 시작 부분 받쳐 더 안 들어가게
  6. Cap은 검지로 막은 채 바로 전달
기준1 level = screw 4개 + rod 50
STEP 7Cap 체결 · Final

딸깍 소리 날 때까지

  1. 한쪽 cap 4개 박기 (screw driver는 보이는 곳에)
  2. Lateral check → cap driver로 한 번 더
  3. 보라 T handle + sleeve + anti-torque 맞물려 전달
  4. 딸깍 될 때까지 torque
  5. 어시가 막대기 하나씩 꺾어 제거
  6. 별 드라이버 전달 → rod handle 풀기 → 반대쪽 반복
순서왼-오-왼-오 순차로, rod 2개 다 끼운 뒤 cap 4개
반대쪽Rod가 길어서 90도로 넣음
STEP 8세척 · 봉합 · 드레싱

댐 만들고 세척

  1. 양쪽 ST + 중포로 댐 만들기 (물이 흐르니까)
  2. Spoid saline → 타우로린 원액 irrigation
  3. Art Q 2개 + 유착방지제 팁
  4. Sur 1 (2) → subcu 2/0 (2) → nylon 3/0 대신 stapler W
  5. Wet gauze 두껍게 → 6인치 픽스롤 가로로

STEP 1Hardware removal

T27 별 driver로 빼기

  1. Mess 10, Lt부터 기존 screw 자리 incision
  2. Mastoid 아래위로 → ray gauze + Cobb으로 박리 → set screw 노출
  3. Rongeur로 자라난 soft tissue 정리
  4. T27 별 driver shaft + handle → set screw 빼기
  5. Rod는 손으로
  6. Screw driver에 시계방향으로 걸고 → 반시계방향으로 빼기
  7. Rt도 동일
기록나온 screw를 L1·L2·L3별 사이즈로 바로 적기 — 새 screw 길이 기준
STEP 2절개 확장 · 골이식재 준비

Novosis + DBM 섞기

Novosis
0.25 g (0.5cc)
OSG DBM
5 cc
  1. Midline incision → Cobb으로 벌리고 self 걸기
  2. 깊어지면 세라벨라 single 2개 (위 mastoid / 아래 세라벨라)
  3. Novosis는 써큐가 믹스 — 사용법 확인
  4. OSG DBM 5cc와 섞어 민무늬 숟가락으로
오염 주의홈 파인 숟가락은 컨타 위험 → 민무늬로
기구Forcep은 cushing S, impactor는 두꺼운 것·얇은 것 둘 다
STEP 3Decortication · Bone graft

뼈를 갈고 채워 넣기

  1. Anspach burr 4mm (물 안 뿌림)로 bone 갈기 — 피가 나와야 잘 붙음
  2. Bone chip 15cc + saline → baby rongeur로 잘게
  3. 얇은 impactor로 밀어 넣기
  4. Screw 자리는 ball probe로 확인하며 forcep 뒷부분으로
  5. BG 끝나면 spoid irrigation
  6. Midline fascia까지 sur 1 하나 닫아두기
STEP 4새 screw · T10–L4

기존 구멍 먼저, 새 레벨은 trocar로

L1–L3Ball probe로 깊이 check → 바로 guide wire → screw (trocar 필요 없음)
레벨Trocar
T10, T11뾰족이 (바벨 없음), 검정 대가리 handle 없이 (handle 때문에 바늘이 안 보여서인 듯)
T12–L4바벨 있는 것으로 처음부터
  1. Freer marking → incision → bovie + 손가락 박리
  2. Mallet → cortical 뚫리면 바벨 inner로 교체
  3. Lateral C-arm 보며 더 깊이 → inner 빼고 guide wire → sheath 빼기
  4. Wire 따라 screw, 들어가면 wire 받기
  5. 더 조일 땐 driver의 ring 빼고 주기
  6. Lt 끝나면 Rt도 T10부터
빠지지 않을 때Inner → sliding hammer · Sheath → 검정 핸들
STEP 5Rod · Cap · Final

Rod 250, 자를 땐 타올로

  1. Rod 250 손으로 주고, screw 위에 대고 중간 marking
  2. Rod holder로 잡고 assi가 잡아주면 bender로 lordosis·kyphosis
  3. 길면 cutter(작두)로 절단
  4. Holder 물린 채 driver로 단단히 → assi는 freer
  5. Rod 위치 잡히면 set screw 바로바로
  6. Cap driver → anti-torque + 보라 T final → 하나씩 꺾어 sleeve 제거
  7. Rod holder key 풀기 → 반대쪽 동일
절단파편 튐 → 소탭이나 가운 타올로 막기
STEP 6세척 · 봉합 · 드레싱

Drain 연결까지

  1. ST 덮고 C-arm check
  2. ST 양쪽으로 막고 spoid irrigation (타우로린 원액)
  3. Sur 1 → mastoid·langen army 벌려 sur 2/0 → nylon 3/0
  4. 바로 위에 Curasys M 2개, 스티커 잘라 붙이기
  5. Mess로 구멍 → suction 확인 → line 동그랗게 붙여 연결
  6. 거즈 두껍게 → surgical pad → 픽스롤 6″ 4개
